# 2026-09 优化与验收记录

## 录音与字幕隔离

新增持久 ASR isolate、单消息 ACK、8 秒有界队列、启动/处理/收尾超时。
音频先落盘，字幕失败不阻止录音；结束时音频先完成，再等待字幕最终清单。
增加并发/延迟/失败/暂停 FIFO 测试。恢复清单改为串行原子替换。
注意这不是进程隔离：native crash、系统强行停止、存储写入失败仍需专门处理和验收。

## 中英离线识别

- 引擎固定 sherpa-onnx 1.13.8；保留原中文 14M 模型，增加 small bilingual zh-en INT8（约 47 MB）。
- 热词用 CJK+BPE 分词及 modified beam search；中文低负载模式无热词时保留 greedy search。
- 两套模型均带 SHA-256，模型文件在安装包内，首次安装后不依赖网络。
- 新增手机“验证当前离线模型”按钮，不调用麦克风或云端。

### 可复现的小样本检查

运行：`uv run --with sherpa-onnx==1.13.8 --with numpy python tool/benchmark_asr.py`。
输入是官方模型包中 10.053 秒、4.690 秒的两段中英夹杂示例，不是用户录音。
Mac 本次测得：中文模型把星期词和 FREQUENTLY 音译为错误中文；双语模型能输出
MONDAY、DAY AFTER TOMORROW、FREQUENTLY，但仍有漏词和中文错误。
双语模型的两段解码 RTF 约 0.09 / 0.114（小于 1 表示本机解码快于音频长度）。
这只是宿主机烟雾测试，不是手机耗电/实时性或一般会议准确率指标。

排查中同一 Python 测试在 1.13.4 返回异常少的文字，1.13.8 恢复；这足以要求升级并回归，
但不能据此把用户此前的所有识别问题都归因于版本。远场音质和领域词依然重要。
